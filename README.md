# terminal

A **cross-platform** terminal built on [`libghostty-vt`](https://lib.ghostty.org/vt/) & [`GPUI`](https://gpui.rs/).

## Features

- Fast & lightweight
- Multi Tab & Window
- i18n
- Catppuccin themes & light/dark theme
- Font customization
- Kitty image & image paste
- Link highlight & open link
- Scrollbar & large buffer (~500MB)
- Switch `pwsh/powershell/cmd` on Windows
